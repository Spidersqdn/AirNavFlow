# คำถามพบบ่อยและแก้ปัญหาเบื้องต้น

ฉบับเริ่มต้น อ้างอิงซอร์สเดียวกับ [USER_GUIDE.md](USER_GUIDE.md)
เป็นคำตอบจากเอกสารและโค้ด ไม่ใช่การวินิจฉัยอุปกรณ์ของผู้ใช้
หากทำตามแล้วไม่สำเร็จ ใช้ [FEEDBACK.md](FEEDBACK.md) รวบรวมรายละเอียดต่อ

<a id="faq-01"></a>
## FAQ-01 — เปิดแอปออฟไลน์แล้วแผนที่ว่าง

ตรวจว่าดาวน์โหลดสำเร็จที่ Offline Maps และเลือกชั้น **แผนที่ออฟไลน์ (OSM)**
ภาพดาวเทียมต้องใช้เน็ต; การเพิ่มไอคอน PWA อย่างเดียวไม่ได้ดาวน์โหลดแผนที่ทั้งหมด
ถ้ายังไม่ได้โหลด ให้กลับออนไลน์และกด Download Map ก่อน
อ้างอิง: [USE-02](USER_GUIDE.md#use-02)

<a id="faq-02"></a>
## FAQ-02 — Download Map / Download Terrain กดไม่ได้

ตรวจว่าออนไลน์และไม่มีการดาวน์โหลดค้างอยู่ แล้วอ่านข้อความสถานะข้างปุ่ม
ถ้าระบุว่ายังไม่มีไฟล์บนเว็บไซต์ ให้ส่งข้อความนั้นให้ผู้ดูแลตรวจระบบเผยแพร่ข้อมูล
bot ไม่ควรสรุปว่าพื้นที่เครื่องเต็มจากปุ่มที่กดไม่ได้เพียงอย่างเดียว
อ้างอิง: [USE-02](USER_GUIDE.md#use-02)

<a id="faq-03"></a>
## FAQ-03 — ไม่มี Contour หรือ Highest ELEV

ตรวจ Download Terrain ให้เสร็จ และเปิด layer **เส้นชั้นความสูง (Contour ft)** เมื่อต้องการเส้นชั้นความสูง
กราฟเส้นทางต้องมีอย่างน้อย 2 จุด; หากยังไม่เห็น Contour ให้ลองซูมเข้าเพื่อดูรายละเอียด
ค่าความสูง terrain เป็นพื้นดิน ส่วน ALTITUDE ใน NAVIGATION TRACKING เป็นค่าจาก GPS
อ้างอิง: [USE-02](USER_GUIDE.md#use-02), [USE-09](USER_GUIDE.md#use-09)

<a id="faq-04"></a>
## FAQ-04 — ค้นหาสถานที่ออฟไลน์ไม่พบ

ต้องมีทั้งแผนที่และดัชนีสถานที่ที่เก็บไว้; ตรวจข้อความค้นหาออฟไลน์ใน Offline Maps
กลับออนไลน์ เปิดแอปให้โหลดดัชนีหรือใช้ Update Map แล้วตรวจสถานะอีกครั้ง
ลองค้นด้วย ICAO สำหรับสนามบิน; การไม่พบสถานที่ในดัชนีไม่ยืนยันว่าสถานที่นั้นไม่มีจริง
อ้างอิง: [USE-02](USER_GUIDE.md#use-02), [USE-03](USER_GUIDE.md#use-03)

<a id="faq-05"></a>
## FAQ-05 — เปิดแอปใหม่แล้วชาร์ตที่นำเข้าหาย/ขอให้เลือกไฟล์ใหม่

ไฟล์ CHART ส่วนตัวอ่านจากต้นฉบับ ไม่ได้คัดลอกเข้าแอป
Safari ต้องเลือกไฟล์เดิมใหม่ใน session ใหม่; เบราว์เซอร์ที่รองรับการจำไฟล์อาจขอสิทธิ์อ่านอีกครั้ง
อย่าใช้ RESET เป็นขั้นแรก เพราะอาจล้างการตั้งค่าที่ต้องการเก็บไว้
อ้างอิง: [USE-07](USER_GUIDE.md#use-07)

<a id="faq-06"></a>
## FAQ-06 — เลือกชาร์ตหรือ ENROUTE แล้วไม่เห็นบนแผนที่

ตรวจว่าเลือกไฟล์ถูกต้อง และเอาเครื่องหมายซ่อนออกในส่วนที่เกี่ยวข้อง:
**HIDE CHARTs** สำหรับชาร์ต หรือ **HIDE ENROUTE Charts / MAPs** สำหรับ MAP
ถ้ายังไม่ได้กำหนดพิกัด ให้ใช้ SET CHARTs / SET MAP ตามชนิดไฟล์
ไฟล์ PDF ต้องมีตัวอ่าน PDF พร้อมด้วย; การเก็บไฟล์ออฟไลน์อย่างเดียวไม่รับประกันการเปิดในทุก session
อ้างอิง: [USE-07](USER_GUIDE.md#use-07), [USE-08](USER_GUIDE.md#use-08)

<a id="faq-07"></a>
## FAQ-07 — TRACK / PPOS ไม่ได้ตำแหน่ง หรือหยุดเมื่อสลับแอป

ตรวจบริการตำแหน่งของเครื่องและสิทธิ์ตำแหน่งของเบราว์เซอร์/PWA
เปิดแอปไว้ด้านหน้าแล้วลอง PPOS; ถ้ายังผิดปกติ เก็บข้อความ error และอุปกรณ์ที่ใช้
PWA ไม่รับประกันการบันทึก GPS ต่อเนื่องเมื่อสลับแอปหรือล็อกหน้าจอ
อ้างอิง: [USE-09](USER_GUIDE.md#use-09)

<a id="faq-08"></a>
## FAQ-08 — แผนเส้นทางยังอยู่ แต่ GPS track หายหลังรีโหลด

เป็นข้อมูลคนละชุด: แผนเส้นทางบันทึกในเบราว์เซอร์ ส่วน GPS track เก็บเฉพาะ session ปัจจุบัน
ใช้ **EXPORT ใน NAVIGATION TRACKING** ก่อนรีโหลดหรือปิดแอปหากต้องเก็บ track
คู่มือไม่มีวิธีกู้ track ที่ไม่ได้ export หลัง session หายไป
อ้างอิง: [USE-04](USER_GUIDE.md#use-04), [USE-09](USER_GUIDE.md#use-09)

<a id="faq-09"></a>
## FAQ-09 — เมนูซูมไม่ได้ แต่แผนที่ซูมได้ ปกติไหม

ปกติครับ เมนูบนอุปกรณ์สัมผัสถูกล็อกการซูมและปรับช่องกรอกเพื่อลดการซูมอัตโนมัติ
ยังเลื่อนเมนูได้ และแผนที่ยังซูมเข้า–ออกได้
ถ้าแผนที่ซูมไม่ได้ด้วย ให้แจ้งอุปกรณ์ เบราว์เซอร์ และจุดที่แตะ เพื่อแยกเป็นปัญหาอื่น
อ้างอิง: [USE-01](USER_GUIDE.md#use-01)

<a id="faq-10"></a>
## FAQ-10 — NOTAM ไม่อัปเดต หรือวันที่เก่า

ตรวจอินเทอร์เน็ตและวันที่/สถานะที่แอปแสดง; ออฟไลน์อาจใช้สำเนาที่เคยโหลดไว้
กลับออนไลน์และเปิดแอปอีกครั้งหลังเก็บ GPS track ที่ต้องการแล้ว
ถ้ายังเก่า ให้แจ้งวันที่ที่พบและข้อความสถานะเพื่อให้ผู้ดูแลตรวจงานนำเข้า
กำหนดเวลา workflow ไม่ได้ยืนยันว่า NOTAM ในเครื่องครบถ้วนหรือเป็นฉบับปัจจุบัน
อ้างอิง: [USE-10](USER_GUIDE.md#use-10), [ROUTINES.md](ROUTINES.md)

<a id="faq-11"></a>
## FAQ-11 — แชร์ไม่ได้ หรือภาพ/PPT ที่ส่งออกดูไม่เหมือนตอนออนไลน์

ตรวจว่ามีอย่างน้อย 2 จุดสำหรับเอกสารเส้นทาง และรอสร้างไฟล์ให้เสร็จก่อนกดส่ง
เลือกบันทึก/ดาวน์โหลดไฟล์เมื่อเบราว์เซอร์ไม่มีการแชร์ที่รองรับ
ภาพพื้นหลังออนไลน์และฟอนต์อาจไม่พร้อมเมื่อออฟไลน์ หรือฟอนต์เครื่องปลายทางต่างกัน
ระบุชนิดไฟล์ ชื่อปุ่ม อุปกรณ์ และข้อความ error หากยังส่งออกไม่ได้
การนำเข้า PDF ต้องใช้ตัวอ่านจากอินเทอร์เน็ตเมื่อยังไม่พร้อม ไม่ใช่ข้อกำหนดเดียวกับการส่งออก PDF/PPT
อ้างอิง: [USE-05](USER_GUIDE.md#use-05), [USE-06](USER_GUIDE.md#use-06), [USE-07](USER_GUIDE.md#use-07)

<a id="faq-12"></a>
## FAQ-12 — จะแจ้งบั๊ก ข้อมูลผิด หรือเสนอฟีเจอร์อย่างไร

บอกว่าทำอะไรอยู่ คาดหวังอะไร และพบอะไรจริง; ถ้าเป็นข้อมูลผิด ให้ระบุจุด/สนามบิน/เอกสารอ้างอิงถ้ามี
ชุดคู่มือนี้ยังไม่มีช่องทาง bot หรือระบบส่งเรื่องอัตโนมัติที่เลือกไว้
bot ช่วยสรุปเรื่องได้ แต่ต้องไม่บอกว่าบันทึกแล้วหากยังไม่มีคำยืนยันจากระบบปลายทาง
อ้างอิง: [FEEDBACK.md](FEEDBACK.md)
