# คำถามพบบ่อยและแก้ปัญหาเบื้องต้น

อัปเดตอ้างอิงซอร์สเดียวกับ [USER_GUIDE.md](USER_GUIDE.md) (v190)
เป็นคำตอบจากเอกสารและโค้ด ไม่ใช่การวินิจฉัยอุปกรณ์ของผู้ใช้
หากทำตามแล้วไม่สำเร็จ ใช้ [FEEDBACK.md](FEEDBACK.md) รวบรวมรายละเอียดต่อ

<a id="faq-01"></a>
## FAQ-01 — เปิดแอปออฟไลน์แล้วแผนที่ว่าง

ตรวจว่าดาวน์โหลดสำเร็จใน **OFFLINE DATA → OSM MAP** และเลือกชั้น **แผนที่ออฟไลน์ (OSM)**
ภาพดาวเทียมต้องใช้เน็ต; การเพิ่มไอคอน PWA อย่างเดียวไม่ได้ดาวน์โหลดแผนที่ทั้งหมด
ถ้ายังไม่ได้โหลด ให้กลับออนไลน์และกด **Download** ที่แถว `OSM MAP` ก่อน
อ้างอิง: [USE-02](USER_GUIDE.md#use-02)

<a id="faq-02"></a>
## FAQ-02 — ปุ่ม Download ใน OFFLINE DATA กดไม่ได้

ตรวจว่าออนไลน์และไม่มีการดาวน์โหลดค้างอยู่ แล้วอ่านข้อความสถานะในแถวนั้น (`OSM MAP` / `TERRAIN` / `ENROUTE` / `CHART`)
สำหรับแถว `CHART` ต้องกด **🔓 LOGIN** ในส่วน CHART เพื่อปลดล็อกรายการชาร์ตในแอปก่อน
ถ้าระบุว่ายังไม่มีไฟล์บนเว็บ ให้ส่งข้อความนั้นให้ผู้ดูแลตรวจระบบเผยแพร่ข้อมูล; bot ไม่ควรสรุปว่าพื้นที่เครื่องเต็มจากปุ่มที่กดไม่ได้อย่างเดียว
อ้างอิง: [USE-02](USER_GUIDE.md#use-02), [USE-07](USER_GUIDE.md#use-07)

<a id="faq-03"></a>
## FAQ-03 — ไม่มี Contour หรือ Highest ELEV

ตรวจว่าโหลด **OFFLINE DATA → TERRAIN** เสร็จแล้ว และเปิด layer **เส้นชั้นความสูง (Contour ft)** เมื่อต้องการเส้นชั้นความสูง
กราฟ `Elevation Profile` ต้องมีอย่างน้อย 2 จุด; หากยังไม่เห็น Contour ให้ลองซูมเข้าเพื่อดูรายละเอียด
ค่าความสูง terrain เป็นพื้นดิน ส่วน `ALTITUDE` ใน `NAVIGATION TRACKING` เป็นค่าจาก GPS
อ้างอิง: [USE-02](USER_GUIDE.md#use-02), [USE-09](USER_GUIDE.md#use-09)

<a id="faq-04"></a>
## FAQ-04 — ค้นหาสถานที่ออฟไลน์ไม่พบ

ต้องมีทั้งแผนที่และดัชนีสถานที่ที่เก็บไว้; ตรวจสัญลักษณ์ `🔎` ในสถานะแถว `OSM MAP` ของ **OFFLINE DATA**
กลับออนไลน์ เปิดแอปให้โหลดดัชนีหรือกด **Update** ที่แถว `OSM MAP` แล้วตรวจสถานะอีกครั้ง
ลองค้นด้วย ICAO สำหรับสนามบิน; การไม่พบสถานที่ในดัชนีไม่ยืนยันว่าสถานที่นั้นไม่มีจริง
อ้างอิง: [USE-02](USER_GUIDE.md#use-02), [USE-03](USER_GUIDE.md#use-03)

<a id="faq-05"></a>
## FAQ-05 — เปิดแอปใหม่แล้วชาร์ตที่นำเข้าหาย/ขอให้เลือกไฟล์ใหม่ หรือไม่เห็นชาร์ตในแอป

- **ชาร์ตส่วนตัวที่นำเข้า (`📄 IMPORT`):** อ่านจากไฟล์ต้นฉบับ ไม่คัดลอกเข้าแอป Safari ต้องเลือกไฟล์เดิมใหม่ใน session ใหม่ ส่วน Chrome/Edge อาจขอสิทธิ์อ่านอีกครั้ง อย่ากด **🗑 RESET** เป็นขั้นแรกเพราะจะล้างการตั้งค่าที่เก็บไว้
- **ชาร์ตในแอป (เข้ารหัส):** แอปไม่ล็อกอินอัตโนมัติเมื่อเปิด ให้กด **🔓 LOGIN** ในส่วน **CHART** เพื่อกรอกรหัสผ่านหรือใช้ Face ID / ลายนิ้วมือ (ที่ลงทะเบียนหลังล็อกอินครั้งแรก)
อ้างอิง: [USE-07](USER_GUIDE.md#use-07)

<a id="faq-06"></a>
## FAQ-06 — เลือกชาร์ตหรือ ENROUTE แล้วไม่เห็นบนแผนที่

ตรวจว่าเลือกไฟล์ถูกช่อง (`DEP CHART`, `ARR CHART`, `MAP`) และติ๊กแสดงผลแล้ว:
**SHOW CHART** (หรือ `SHOW` บนแถบชาร์ต) สำหรับชาร์ต, **SHOW MAP** (หรือ `SHOW` ในช่อง `MAP+ENROUTE`) สำหรับ MAP/ENROUTE
ถ้าเป็นไฟล์ภาพ/PDF ที่นำเข้าเองและยังไม่ตั้งพิกัด ให้ใช้ **📍 SET CHART** / **📍 SET MAP** ก่อน
หากเปิด PDF ออฟไลน์ไม่ได้ ให้ต่ออินเทอร์เน็ตแล้วเปิดแอปใหม่ 1 ครั้งเพื่อให้ PWA แคชตัวอ่าน PDF (`lib/pdf.min.js`)
อ้างอิง: [USE-07](USER_GUIDE.md#use-07), [USE-08](USER_GUIDE.md#use-08)

<a id="faq-07"></a>
## FAQ-07 — TRACK / PPOS ไม่ได้ตำแหน่ง หรือหยุดเมื่อสลับแอป

ตรวจบริการตำแหน่งของเครื่องและสิทธิ์ตำแหน่งของเบราว์เซอร์/PWA
เปิดแอปไว้ด้านหน้าแล้วลอง **PPOS**; ถ้ายังผิดปกติ เก็บข้อความ error และอุปกรณ์ที่ใช้
PWA ไม่รับประกันการบันทึก GPS ต่อเนื่องเมื่อสลับแอปหรือล็อกหน้าจอ
อ้างอิง: [USE-09](USER_GUIDE.md#use-09)

<a id="faq-08"></a>
## FAQ-08 — แผนเส้นทางยังอยู่ แต่ GPS track หายหลังรีโหลด

เป็นข้อมูลคนละชุด: แผนเส้นทางบันทึกในเบราว์เซอร์ ส่วน GPS track เก็บเฉพาะ session ปัจจุบัน
ใช้ **EXPORT ใน NAVIGATION TRACKING** ก่อนรีโหลดหรือปิดแอปหากต้องเก็บ track
คู่มือไม่มีวิธีกู้ track ที่ไม่ได้ export หลัง session หายไป
อ้างอิง: [USE-04](USER_GUIDE.md#use-04), [USE-09](USER_GUIDE.md#use-09)

<a id="faq-09"></a>
## FAQ-09 — เมนูซูมไม่ได้ แต่แผนที่ซูมได้ ปกติไหม

ปกติครับ เมนูและแถบด้านล่างบนอุปกรณ์สัมผัสถูกล็อกการซูมเพื่อลดการซูมอัตโนมัติ
ยังเลื่อนเมนูได้ และแผนที่ยังซูมเข้า–ออกด้วยนิ้วได้ตามปกติ
ถ้าแผนที่ซูมไม่ได้ด้วย ให้แจ้งอุปกรณ์ เบราว์เซอร์ และจุดที่แตะ เพื่อแยกเป็นปัญหาอื่น
อ้างอิง: [USE-01](USER_GUIDE.md#use-01)

<a id="faq-10"></a>
## FAQ-10 — NOTAM ไม่อัปเดต วันที่เก่า หรือไม่ขึ้นในสไลด์ NOTAM

ตรวจอินเทอร์เน็ตและวันที่/สถานะที่แอปแสดง; ออฟไลน์จะใช้สำเนาที่เคยโหลดไว้ (ควร export GPS track ก่อนรีโหลด)
สำหรับปุ่ม **NOTAM** (สไลด์): แอปกรองเฉพาะ NOTAM ที่ active ณ เวลาที่เลือก (`B)` ถึง `C)` ไม่ดู `D)`) และห่างเส้นทางหลัก/สำรองไม่เกินระยะที่ตั้ง (ค่าเริ่มต้น 20 NM) ลองตรวจเวลา ระยะห่าง หรือตัวเลือก **รวม NOTAM ทั้ง FIR** และรายการติ๊กเลือก NOTAM
กำหนดเวลา workflow ไม่ได้ยืนยันว่า NOTAM ในเครื่องครบถ้วนหรือเป็นฉบับปัจจุบัน ตรวจเทียบแหล่งทางการเสมอ
อ้างอิง: [USE-06](USER_GUIDE.md#use-06), [USE-10](USER_GUIDE.md#use-10), [ROUTINES.md](ROUTINES.md)

<a id="faq-11"></a>
## FAQ-11 — แชร์ไม่ได้ หรือภาพ/PDF/PPT ที่ส่งออกดูไม่เหมือนตอนออนไลน์

ตรวจว่ามีอย่างน้อย 2 จุดสำหรับเอกสารเส้นทาง และรอสร้างไฟล์ให้เสร็จก่อนกดส่ง (บน iOS ต้องกดปุ่มส่งอีกครั้งหลังเตรียมไฟล์เสร็จ)
เลือกบันทึก/ดาวน์โหลดไฟล์เมื่อเบราว์เซอร์ไม่รองรับการแชร์ไฟล์
ภาพพื้นหลังออนไลน์และฟอนต์อาจไม่พร้อมเมื่อออฟไลน์ หรือฟอนต์เครื่องปลายทางต่างกัน
ระบุชนิดไฟล์ ชื่อปุ่ม อุปกรณ์ และข้อความ error หากยังส่งออกไม่ได้
อ้างอิง: [USE-05](USER_GUIDE.md#use-05), [USE-06](USER_GUIDE.md#use-06)

<a id="faq-12"></a>
## FAQ-12 — จะแจ้งบั๊ก ข้อมูลผิด หรือเสนอฟีเจอร์อย่างไร

บอกว่าทำอะไรอยู่ คาดหวังอะไร และพบอะไรจริง; ถ้าเป็นข้อมูลผิด ให้ระบุจุด/สนามบิน/เอกสารอ้างอิงถ้ามี
ชุดคู่มือนี้ยังไม่มีช่องทาง bot หรือระบบส่งเรื่องอัตโนมัติที่เลือกไว้
bot ช่วยสรุปเรื่องได้ แต่ต้องไม่บอกว่าบันทึกแล้วหากยังไม่มีคำยืนยันจากระบบปลายทาง
อ้างอิง: [FEEDBACK.md](FEEDBACK.md)
