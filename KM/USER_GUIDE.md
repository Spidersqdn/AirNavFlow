# คู่มือใช้งาน AirNavFlow สำหรับผู้ใช้และ bot

ฉบับเริ่มต้น อ้างอิงซอร์ส [8749ca4](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html)
ตรวจชื่อปุ่มและพฤติกรรมจากโค้ด; ไม่ใช่ผลทดสอบครบทุกอุปกรณ์
AirNavFlow ใช้เพื่อวางแผนการบิน ข้อมูล AIP/NOTAM ทางการเป็นหลักในการตรวจข้อมูล

<a id="use-01"></a>
## USE-01 — เปิดแอป ติดตั้ง และหาเมนู

1. เปิด https://spidersqdn.github.io/AirNavFlow/ ขณะมีอินเทอร์เน็ต
2. iPhone/iPad: เปิดด้วย Safari แล้วใช้เมนูแชร์ของเบราว์เซอร์ → เพิ่มไปยังหน้าจอโฮม
   Android: เปิดด้วย Chrome แล้วเลือกเมนูติดตั้งแอป/เพิ่มไปยังหน้าจอหลักตามรุ่นเบราว์เซอร์
3. เปิดจากไอคอน AirNavFlow เพื่อใช้งานเป็น PWA
4. เมนูหลักอยู่ซ้ายในแนวนอน และด้านล่างในแนวตั้ง; เลื่อนภายในเมนูเพื่อดูส่วนอื่น
5. ถ้าเมนูถูกซ่อน ใช้ปุ่มลูกศรขอบแผนที่เพื่อแสดงเมนูอีกครั้ง
6. บนอุปกรณ์สัมผัส เมนูถูกล็อกการซูม แต่ยังเลื่อนได้; แผนที่ยังซูมด้วยนิ้วได้

แหล่งอ้างอิง: [การติดตั้ง](../README.md), [เมนูและการซูม](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L790)

<a id="use-02"></a>
## USE-02 — เตรียมใช้ออฟไลน์

1. ต่ออินเทอร์เน็ต แล้วเลื่อนเมนูไปส่วน **Offline Maps**
2. กด **Download Map** และรอจนแสดงว่ามีแผนที่ในเครื่องแล้ว
3. ที่ **Elevation & Terrain Data** กด **Download Terrain** ถ้าต้องการความสูง/Contour ออฟไลน์
4. เปิดเมนูชั้นแผนที่ เลือก **แผนที่ออฟไลน์ (OSM)**
5. เปิด **เส้นชั้นความสูง (Contour ft)** เมื่อต้องการดู Contour และมีข้อมูลความสูงพร้อมแล้ว
6. หลังดาวน์โหลดครบ ทดลองเปิดแอปและใช้งานโดยปิดอินเทอร์เน็ต
   ถ้าจะใช้ตำแหน่ง ให้เปิดบริการตำแหน่งของเครื่องและอนุญาตแอป/เบราว์เซอร์

เมื่อเคยดาวน์โหลดแล้ว ปุ่มเปลี่ยนเป็น **Update Map** / **Update Terrain**
การดาวน์โหลดแผนที่พยายามเก็บดัชนีค้นหาสถานที่ด้วย; ตรวจข้อความว่าค้นหาออฟไลน์ได้ก่อนใช้งาน
ภาพดาวเทียม WINDY เรดาร์ฝน และ NOTAM ฉบับใหม่ต้องใช้อินเทอร์เน็ต
ไฟล์ชาร์ตและแผนที่ที่นำเข้าแยกต่างหากไม่ได้รวมใน Download Map ดู USE-07/08
ความสูงจาก terrain คือระดับพื้นดิน ไม่รวมสิ่งกีดขวาง และไม่ใช่ MSA

แหล่งอ้างอิง: [การดาวน์โหลดและสถานะออฟไลน์](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L11451), [ชั้นแผนที่](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L5558)

<a id="use-03"></a>
## USE-03 — เพิ่มจุดและคำนวณเส้นทาง

- **AIRPORT**: กรอกชื่อสนามบินหรือ ICAO ในช่อง Airport Name / ICAO แล้วกด **Add ROUTE**
- **LAT/LONG**: กรอก LAT 6 หลัก DDMMmm และ LONG 7 หลัก DDDMMmm
  เช่น LAT 135475 = N13°54.75′ และ LONG 0994500 = E099°45.00′ แล้วกด **Add ROUTE**
- **RADIAL/DME**: กรอกสนามบินอ้างอิง ICAO, Radial และ DME (NM) แล้วกด **Add ROUTE**
  Radial ในการคำนวณนี้อ้างทิศเหนือจริง ไม่ใช่ทิศเหนือแม่เหล็ก
- บนแผนที่: เปิด **On MAP** → แตะตำแหน่ง → เลือก **Add ROUTE**
  กด **On MAP** อีกครั้งเพื่อออกจากโหมดเพิ่มจุด
- ใช้ **Add Off-ROUTE W.Pt** เพื่อเก็บจุดนอกเส้นทาง; เปิด layer **OFF-ROUTE Wpt** หากต้องการเห็นจุด
- กรอก Remark ได้ตามต้องการ และตรวจ Airspeed (kt), FUEL, Fuel Consumption ให้ตรงกับแผน
- เมื่อมีอย่างน้อย 2 จุด แอปแสดงระยะ เวลา น้ำมัน และกราฟความสูงตามข้อมูลที่พร้อม

ช่องค้นหาด้านบนใช้ค้น ICAO/สถานที่; การค้นพบตำแหน่งยังไม่เท่ากับเพิ่มจุดในเส้นทาง
ออนไลน์ใช้การค้นหาสถานที่ออนไลน์; ออฟไลน์ต้องมีแผนที่และดัชนีสถานที่ในเครื่อง

แหล่งอ้างอิง: [ช่องเพิ่มจุด](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L1794), [ค้นหาและเพิ่มจุด](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L11158)

<a id="use-04"></a>
## USE-04 — เส้นทางหลัก/สำรองและการบันทึก

- เลือก **เส้นทางหลัก** หรือ **เส้นทางสำรอง** เพื่อเปลี่ยนชุดเส้นทางที่กำลังแก้ไข
- **⇄** สลับข้อมูลสองเส้นทาง; **✕** ข้างเส้นทางสำรองใช้ลบเส้นทางสำรองหลังยืนยัน
- **BACK TRACK** กลับลำดับจุดในเส้นทางที่กำลังแก้ไข; ต้องมีอย่างน้อย 2 จุด กดอีกครั้งเพื่อกลับลำดับเดิม
- **BACK** ลบจุดสุดท้ายของเส้นทางที่กำลังแก้ไข ไม่ใช่ undo ทุกประเภท
- **CLEAR ROUTE** ล้างเส้นทางที่กำลังแก้ไขทันที
- แผนเส้นทางบันทึกในข้อมูลของเบราว์เซอร์นี้อัตโนมัติ ไม่ได้ซิงก์ข้ามเครื่อง
  ใช้ EXPORT เก็บไฟล์ก่อนย้ายเครื่องหรือล้างข้อมูลเบราว์เซอร์

GPS track ที่บันทึกระหว่างใช้งานมีพฤติกรรมต่างกัน ดู USE-09

แหล่งอ้างอิง: [สลับเส้นทาง](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L5896), [บันทึก/โหลดเส้นทาง](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L11405)

<a id="use-05"></a>
## USE-05 — EXPORT / IMPORT เส้นทาง

1. เลือกเส้นทางหลักหรือสำรองที่ต้องการ และมีอย่างน้อย 2 จุดก่อน EXPORT
2. กด **EXPORT** ใต้ตารางเส้นทาง แล้วเลือก KMZ / KML / GPX / CSV
3. เลือกกลุ่ม Off-Route: **1. All W.Pt** หรือ **2. W.Pt with in 20NM**
   เลือกจุดที่ต้องการแล้วกดปุ่ม EXPORT ของชนิดไฟล์นั้น
4. **3. No W.Pt (for FalCon2CP, KMZ)** ส่งออกเป็น KMZ โดยไม่รวมจุด Off-Route
5. **EXPORT สำรองเส้นทางเดิมก่อน IMPORT** แล้วเลือกไฟล์ KMZ/KML/GPX/CSV ที่ต้องการนำเข้า
   ถ้ามีเส้นทางเดิมและไฟล์มี route แอปให้เลือกวิธีนำเข้า; บางไฟล์อาจแทนที่เส้นทางทันทีโดยไม่มีหน้าถาม
   ในซอร์สที่ตรวจ ไฟล์ที่มีเฉพาะ Off-Route สามารถล้างเส้นทางที่กำลังแก้ไขได้ จึงต้องสำรองก่อน

EXPORT ในแผง NAVIGATION TRACKING เป็นการส่ง GPS track คนละชุดกับ EXPORT เส้นทางวางแผน

แหล่งอ้างอิง: [EXPORT](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L6956), [IMPORT](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L7351)

## USE-06 — MINI MAP / MSN CARD / SLIDE

ทั้งสามรายการต้องมีอย่างน้อย 2 จุดในเส้นทางที่เลือก

| ปุ่ม | วิธีใช้งานหลัก | ผลลัพธ์ |
|---|---|---|
| MINI MAP | เลือกมุมมอง MINI MAP/ตาราง ปรับชื่อหรือกล่อง แล้วใช้ PDF, PPT หรือ แชร์ | ภาพ/ตาราง A5 แนวตั้ง; PDF/PPT จัดคู่ลงหน้า A4 แนวนอน |
| MSN CARD | แก้ค่าบนบัตร → อัปเดต → บันทึก PNG หรือ แชร์ | Pilot Mission Data Card เป็น PNG |
| SLIDE | แก้ข้อความ → อัปเดต → บันทึก PNG, PPT หรือ แชร์ | MISSION OVERVIEW แนวนอน 16:9 |

MINI MAP เป็น PNG: กด **แชร์** → **PNG** → ปุ่ม **ส่ง PNG** หรือ **บันทึก PNG** ที่แสดงหลังเตรียมไฟล์
การแชร์ส่งเป็นไฟล์; วิธีเลือกแอปปลายทางขึ้นกับเครื่องและเบราว์เซอร์
พื้นหลังภาพดาวเทียมและฟอนต์อาจต่างเมื่อไม่มีอินเทอร์เน็ตหรือไม่มีฟอนต์ในเครื่องปลายทาง

แหล่งอ้างอิง: [MINI MAP](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L8669), [SLIDE](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L9282), [MSN CARD](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L9690)

<a id="use-07"></a>
## USE-07 — CHART

1. ไปส่วน **CHART** → **📄 IMPORT CHART** → เลือก PDF หรือภาพ PNG/JPG/WebP จากเครื่อง
2. เลือกชาร์ตจากรายการ; ใช้ **👁 VIEW CHARTs** เพื่อดู และลูกศรเปลี่ยนหน้าสำหรับ PDF
3. หากต้องกำหนดตำแหน่งบนแผนที่ ใช้ **📍 SET CHARTs** และจุดอ้างอิงพิกัด 2–3 จุดตามหน้าจอ
4. เอาเครื่องหมาย **HIDE CHARTs** ออกเพื่อแสดงชาร์ตบนแผนที่ แล้วปรับความโปร่งใสตามต้องการ

ชาร์ตที่ผู้ใช้นำเข้าอ่านจากไฟล์ต้นฉบับ ไม่คัดลอกไฟล์เก็บในแอป
เบราว์เซอร์ที่รองรับอาจจำสิทธิ์อ้างอิงไฟล์ได้; Safari ต้องเลือกไฟล์เดิมใหม่เมื่อเริ่ม session ใหม่
ชาร์ตที่มากับแอปอยู่ในรายการชาร์ต และมีปุ่ม **⬇ เก็บชาร์ตในแอพไว้ใช้ออฟไลน์** เมื่อรายการพร้อม
ปุ่มนี้ใช้กับชาร์ตที่มากับแอป ไม่ใช่การบันทึกไฟล์ส่วนตัวที่นำเข้า
การอ่าน PDF ต้องโหลดตัวอ่านจากอินเทอร์เน็ตเมื่อยังไม่พร้อม; การเก็บ PDF อย่างเดียวไม่รับประกันว่าเปิดออฟไลน์ได้ทุก session
**🗑 RESET** ล้างรายการชาร์ตที่นำเข้าและการตั้งค่าของรายการนั้น แต่ไม่ลบไฟล์ต้นฉบับในเครื่อง

แหล่งอ้างอิง: [CHART UI](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L1941), [การอ่านไฟล์](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L10437), [PDF/ชาร์ตออฟไลน์](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L10719)

<a id="use-08"></a>
## USE-08 — MAP และ ENROUTE

- ส่วน **MAP** ใช้ **📁 IMPORT MAP** นำเข้า .pmtiles หรือ PDF/ภาพ
- สำหรับ PDF/ภาพ ใช้ **📍 SET MAP** กำหนดพิกัด และ **👁 VIEW** เพื่อดู
- เลือก **ENROUTE (AIP)** จากรายการเพื่อใช้แผนที่ที่มากับแอป
- เอาเครื่องหมาย **HIDE ENROUTE Charts / MAPs** ออกเพื่อแสดง overlay
- ตัวเลือก **ก็อปไฟล์เก็บไว้ในแอพ (ไม่ติ๊ก = อ่านจากที่อยู่ไฟล์โดยตรง)** ใช้กำหนดการเก็บไฟล์ MAP
- **🗑 DELETE MAP** ลบรายการที่เลือก; **🗑 CLEAR MAPs** ลบรายการแผนที่ที่นำเข้าทั้งหมดตามการยืนยัน
- **🧹 ล้าง cache แผนที่** ล้างสำเนา MAP ที่เก็บไว้; ทำให้ต้องโหลดหรือเลือกไฟล์ที่จำเป็นใหม่
- PDF MAP มีข้อจำกัดตัวอ่าน PDF เช่นเดียวกับ CHART ใน USE-07

แหล่งอ้างอิง: [MAP UI](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L1963), [นำเข้า MAP](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L10261)

<a id="use-09"></a>
## USE-09 — NAVIGATION TRACKING

| ปุ่ม | ความหมาย |
|---|---|
| TRACK | เปิด/ปิดการรับตำแหน่งและบันทึก GPS track; ต้องอนุญาตตำแหน่ง |
| PPOS | เลื่อนแผนที่ไปตำแหน่ง GPS ที่มี หรือขอตำแหน่งเมื่อยังไม่มี |
| ROUTE | แสดง/ซ่อนเส้น GPS track ที่บันทึก ไม่ใช่เลือกเส้นทางวางแผน |
| RESET | ล้าง track ระยะและเวลาหลังยืนยัน; ไม่ได้ปิด TRACK ที่กำลังทำงาน |
| EXPORT | ส่ง GPS track เป็น KMZ/KML/GPX/CSV หรือภาพ ตามตัวเลือกในหน้าจอ |

การ EXPORT GPS track ต้องมีจุดที่บันทึกอย่างน้อย 2 จุด
ปิดแล้วเปิด TRACK ใหม่ใน session เดิมจะบันทึกต่อ แต่ **รีโหลดแอปแล้ว GPS track จะหาย**
หากต้องเก็บ track ให้ EXPORT ก่อนรีโหลดหรือปิดแอป
เปิดแอปไว้ด้านหน้า; ไม่รับประกันการบันทึกต่อเมื่อสลับแอปหรือล็อกหน้าจอ
ALTITUDE ในแผงนี้มาจาก GPS และอาจไม่มีค่าบนอุปกรณ์บางรุ่น; ไม่ใช่ความสูง terrain

แหล่งอ้างอิง: [ปุ่ม TRACK](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L1923), [อายุข้อมูลและ RESET](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L6443)

## USE-10 — NOTAM, Layer และ WINDY

- แอปพยายามโหลด NOTAM ที่ระบบเผยแพร่ล่าสุด และใช้สำเนาออฟไลน์เมื่อเครือข่ายใช้ไม่ได้
  ตรวจข้อความวันที่/สถานะและเทียบกับข้อมูลทางการ; “โหลดได้” ไม่ได้แปลว่าครบถ้วนหรือเป็นฉบับปัจจุบัน
- วางข้อความเองได้ที่ **+ Upload NOTAM (ICAO Q-line)** แล้วกด **พอร์ตลงแผนที่**
- เปิด layer **Imported NOTAM** ตามต้องการ; รายการ NOTAM ด้านข้างซ่อนไว้เริ่มต้น
- layer **OFF-ROUTE Wpt**, **HIDE CHARTs** และ **HIDE ENROUTE Charts / MAPs** มีค่าเริ่มต้นให้ซ่อนรายการที่เกี่ยวข้อง
- **WINDY** มี DEPARTURE / MidWay / DESTINATION และต้องใช้อินเทอร์เน็ต
- ตารางเวลานำเข้าข้อมูลอยู่ใน [ROUTINES.md](ROUTINES.md)

แหล่งอ้างอิง: [NOTAM UI](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L1903), [โหลด NOTAM](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L11883), [WINDY](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L2012)

## USE-11 — RULER วัดระยะและทิศ

กด **RULER** แล้วแตะจุด A และจุด B บนแผนที่เพื่อดูระยะและทิศ
เมื่อมีสองจุดแล้ว แตะอีกครั้งจะเริ่มวัดคู่ใหม่; กด RULER อีกครั้งเพื่อออกจากโหมดและล้างเส้นวัด
การวัดนี้ไม่เพิ่ม waypoint ลงในเส้นทางวางแผน

แหล่งอ้างอิง: [RULER](https://github.com/Spidersqdn/AirNavFlow/blob/8749ca42c32d39379093e0ae092a3829c3e78d2e/index.html#L6882)
