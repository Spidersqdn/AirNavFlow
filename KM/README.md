# KM — คลังความรู้ AirNavFlow

รวบรวมไฟล์ Markdown สำหรับความรู้ วิธีดูแลระบบ และบันทึกการตัดสินใจของโปรเจกต์

## สารบัญ

| เอกสาร | เนื้อหา |
|---|---|
| [BOT_GUIDE.md](BOT_GUIDE.md) | แนวทางตอบคำถามและเลือกเอกสารสำหรับ bot |
| [USER_GUIDE.md](USER_GUIDE.md) | คู่มือใช้งานตามชื่อปุ่มปัจจุบัน |
| [FAQ.md](FAQ.md) | คำถามพบบ่อยและการแก้ปัญหาเบื้องต้น |
| [FEEDBACK.md](FEEDBACK.md) | แนวทางเก็บและสรุป feedback เพื่อส่งต่อ |
| [ROUTINES.md](ROUTINES.md) | งานอัตโนมัติ กำหนดเวลาไทย และแหล่งอ้างอิง |

สำหรับ bot ให้เริ่มที่ BOT_GUIDE.md; เอกสารชุดนี้ยังไม่ได้เชื่อม bot หรือระบบรับ feedback อัตโนมัติ

## เอกสารหลัก

- [CONTEXT.md](../CONTEXT.md): บริบทโปรเจกต์และกติกาการทำงาน อ่านก่อนเริ่มงาน
- [AGENTS.md](../AGENTS.md): คำแนะนำสำหรับ AI coding agents
- [README.md](../README.md): คู่มือใช้งานแอป
- [AUTOMATION-TH.md](../tools/AUTOMATION-TH.md): วิธีตั้งค่างานอัตโนมัติและแก้ปัญหา

## การเพิ่มความรู้

- แยกไฟล์ตามหัวข้อ และเพิ่มลิงก์ในสารบัญนี้
- แต่ละไฟล์ Markdown ต้องน้อยกว่า 200 บรรทัด
- ระบุวันที่ตรวจสอบและลิงก์แหล่งข้อมูลเมื่อบันทึกข้อเท็จจริงที่เปลี่ยนได้
- ใช้ [Inference], [Speculation] หรือ [Unverified] เมื่อข้อมูลยังไม่ยืนยัน
